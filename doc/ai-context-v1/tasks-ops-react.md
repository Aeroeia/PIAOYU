# 运维场景任务清单（ReAct）

## 目标
- 让 AI 在运维场景具备“思考-执行-观察-再决策”的循环能力。
- 在保证效率的同时，降低误操作风险。

## 任务清单
- [ ] 1. 定义 ReAct 循环协议：`Thought -> Action -> Observation -> Next Action`
- [ ] 2. 接入运维工具：日志查询、监控查询、告警查询、发布与回滚接口
- [ ] 3. 定义工具调用网关：统一参数校验、超时控制、错误映射
- [ ] 4. 实现循环控制：最大轮次、终止条件、人工接管条件
- [ ] 5. 实现高危动作门禁：重启/回滚/扩缩容必须二次确认
- [ ] 6. 实现降级策略：工具不可用时给出替代路径或人工建议
- [ ] 7. 输出诊断结论模板：问题现象、根因判断、已执行动作、建议动作
- [ ] 8. 补齐测试：CPU 飙高排障、接口超时排查、发布后异常回滚、误操作拦截

## 交付物
- 运维 ReAct 编排服务
- 运维工具适配层与高危确认机制
- 典型故障演练脚本与回归用例

## 验收标准
- 常见故障可在有限轮次内完成定位并给出可执行建议。
- 高危动作必须经过确认，且有可追踪的执行过程。
- 工具失败不导致会话崩溃，系统可降级回复。
